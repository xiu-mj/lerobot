# LeRobot 学习笔记

本目录用于存放对 LeRobot 项目各部分的解释和笔记。

## 目录结构

```
notes/
├── README.md              # 本文件 - 目录说明
├── quickstart/            # 快速入门
├── core_modules/          # 核心模块解析
├── api_reference/         # API 参考
└── tutorials/             # 教程
```

## 内容说明

| 文件夹 | 内容 |
|--------|------|
| `quickstart/` | 安装指南、首次训练等快速上手内容 |
| `core_modules/` | 各核心模块（policies、datasets、envs等）的详细解析 |
| `api_reference/` | API 接口说明和使用示例 |
| `tutorials/` | 实践教程，如策略复现、仿真指南等 |
